# SlideShots 0.4.4

![SlideShots アイコン](icons/icon-128.png)

「ページ全体」または「クリックで選んだ内部ページ」を、1回の操作で PNG・JPEG・WebP・PDF に保存する Chrome 拡張機能です。内部スクロール領域と iframe の両方に対応します。

## インストール・更新

1. Chrome の `chrome://extensions` で「デベロッパー モード」をオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」で、この `manifest.json` があるフォルダを選びます。
3. すでに同じフォルダから読み込み済みの場合は、拡張機能の「再読み込み」を押します。
4. 撮影するページも再読み込みします。`file://` のページでは、拡張機能の「ファイルの URL へのアクセスを許可」を有効にしてください。

0.3 ではスライド枚数・次へボタン・CSS セレクターの設定を削除しました。デバッグ権限も使用しません。iframe を含めて操作するためのサイトアクセス権、ダウンロード権限、PDFの大きなファイルを保存するための非表示ページ権限を使用します。

0.3.1 では、固定配置された内部ページを、見えているのに「対象の一部が別の枠で隠れています」と判定する問題を修正しました。親要素の高さが0の配置や、別オリジンの iframe 内でも確認しています。

0.3.2 では、拡張機能の再読み込み・更新後にページへ残った旧スクリプトがコンソールへ `Extension context invalidated.` エラーを出す問題に対処しました。また、撮影を診断するログコンソールを上級者向けに追加しました。非公開環境で「対象の一部が別の枠で隠れています」が引き続き発生する場合の調査に使用します。

0.3.3 では、縮小表示（CSS の scale）された内部領域の最後の1pxが画面上1px未満になることで「対象の一部が別の枠で隠れています」と誤判定する問題を修正しました。ログコンソールの記録から、スクロール末尾の1pxが亜像素として判定に引っかかっていたことを特定しています。

0.3.4 では、結合画像のタイル境界の不自然さを軽減しました。スケールが掛かった領域では境界座標が小数ピクセルになり、境界行がにじむ・二重に見える原因になっていたため、読み取りをデバイスピクセル単位に丸めています。また、CSS トランジション・アニメーション（終わるもの）の完了を待ってから撮影するようにしました。

0.3.5 では、「継ぎ目を検証して撮影」ボタンを追加しました。各タイルを2回撮影して PNG バイト列を比較し、一致＝描画が安定したと確認してから結合します（上限5回再試行）。通常撮影と検証撮影をボタンで切り替えられます。

0.3.7 では、高速モードとデバッグ権限を削除しました。また、縮小された領域の末尾が画面上1px未満でも、内容上のピクセル数で撮影可否を判定するよう修正しました。最後の行・列を切り出す際に、丸めで隣の画素を読んでしまう場合も補正します。

0.3.8 では、結合位置に表示枠の端が混ざって白い帯になる問題に対処しました。少し重なるようにスクロールし、続きの画像は枠の端から離れた位置で切り出します。また、小数ピクセルの幅・高さを整数の寸法で割って誤った倍率にしていた計算を修正しました。

0.3.9 では、横幅が1pxずつ変化した場合にも撮影を中止し、出力画像の幅と完了表示が食い違う問題を修正しました。Shadow DOM 内のスクロール領域を選択したときは、固定配置の祖先を非表示にせず、内部の祖先スクロール位置も終了・中止時に復元します。継ぎ目検証で画像の一致を確認できなかった場合は、最新の画像を使って最後まで撮影を続行し、ログに「検証失敗」と件数を記録します。

0.3.10 では、設定画面を「一般」「詳細」に整理しました。撮影範囲と待ち時間のボタン・ミリ秒指定は「一般」に、継ぎ目検証とログコンソールは「詳細」にあります。

0.4.0 では、詳細から保存先フォルダーと画像形式（PNG・JPEG・WebP）を選べるようにしました。フォルダー選択はブラウザの画面から行い、撮影開始時に書き込み権限を確認します。一般画面の長い補足は情報アイコンに移しました。

0.4.1 では、情報アイコンの説明をカーソルを合わせた瞬間に表示し、クリックした後はカーソルを離しても約3.5秒表示するようにしました。キーボードでアイコンに移動した場合も表示します。

0.4.2 では、詳細の保存形式に PDF を追加しました。A4の複数ページを1ファイルとして保存します。PDFのダウンロードには、巨大なデータURLを作らず、拡張機能内の一時データと非表示ページを使用します。

0.4.3 では、PDFを縦向きA4に統一しました。撮影内容を内部で縦1列の連続画像として保持してから、文字や図がある行を避けてページ境界を選びます。

0.4.4 では、ページ境界を選ぶ際に広い余白とセクションの切り替わりを優先します。実サイトの Home・Projects・About・Contact ページでPDFを確認しました。

## 使い方

### ページ全体

「ページ全体」を選び、「ページ全体を撮影」を押します。外側のページを上から下、横にはみ出す場合は左右にもスクロールして保存します。

ページの中にあるスクロール枠や iframe は、その時点で表示中の部分が写ります。その内部を末尾まで撮るときは「内部ページ」を選びます。

### 内部ページ

1. 「内部ページ」を選び、「ページ上で範囲を選ぶ」を押します。
2. 撮りたい枠や埋め込みページにカーソルを合わせ、緑色の枠を確認してクリックします。
3. 設定画面が戻ったら「選んだ内部ページを撮影」を押します。画面が戻らない場合は拡張機能のアイコンをもう一度押してください。

枠の中のボタンやリンクを選択時にクリックしても、その操作を実行しないようにしています。iframe の中にさらにスクロール領域がある場合は、近い内側の領域が選ばれます。「この埋め込みページ全体に変更」で iframe 文書全体へ切り替えられます。選択の取り消しはページ上部の「キャンセル」です。

別の内部領域を撮る場合は「ページ上で選び直す」を押します。1回につき、選んだ1領域を撮影します。内部領域の中にさらに独立したスクロール枠がある場合、その枠の内容は個別に選択して撮影してください。

### 継ぎ目を検証して撮影

「詳細」で「継ぎ目を検証する」をオンにして撮影すると、1枚を撮るたびに2回撮影して結果を比較し、描画が落ち着いたことを確認してから結合します。スクロールと同時に再描画される文書ビューアーで、継ぎ目のずれ・にじみが気になる場合に使います。撮影時間は通常の約2倍です。「ページ全体」「内部ページ」のどちらでも使えます。

比較が一致しない場合は最大5回まで再比較するため、さらに時間がかかる場合があります。上限まで一致しなくても撮影は中止せず、最新の画像を使って続行します。該当するタイルと失敗件数は、「詳細」のログコンソールに「検証失敗」と表示します。この場合、描画の安定は確認できていません。

## 一般・詳細

- **一般**：撮影範囲を選び、描画待ちを「標準（1秒）／じっくり（2秒）」のボタンまたは 200〜10,000 ms の数値で指定します。文書ビューアーなど読み込みが遅いページでは、待ち時間を長めにしてください。
- **詳細**：保存先、保存形式、継ぎ目検証のオン・オフと、撮影の内部記録（フレーム構造・各タイルの座標と可視範囲・エラーの詳細値）の確認・コピーができます。タブを切り替えても撮影範囲と待ち時間は変わりません。

保存先は、標準の「ダウンロード」（`SlideShots / <日時>`）または「指定フォルダー」（選んだフォルダー内の `<日時>`）です。指定フォルダーを選んだ後、必要に応じて撮影開始時に書き込みを許可してください。JPEG と WebP は画質92%の非可逆圧縮です。文字の輪郭を保ちたい場合は PNG を選んでください。

## 撮影中・保存先

撮影中は対象タブを表示したまま操作せずにお待ちください。タブを切り替えるかウィンドウを最小化すると、別の画面を保存しないよう撮影を中止します。「撮影を停止」でも中止できます。終了・中止時に、拡張機能が変更したスクロール位置や表示設定を戻します。

PNG・JPEG・WebP は通常1枚です。非常に長い画像は、ブラウザの画像サイズ・メモリ制限を避けるため、番号付き画像に分割して全範囲を保存します。分割の目安は1画像の高さ 16,000 px または 3,200万画素です。画像形式で途中にエラーや停止が発生した場合、保存済みの分だけが残り、未完了であることを表示します。

## PDF 保存

「詳細」→「保存形式」で PDF を選びます。撮影した画像を内部で縦1列につなぎ、A4縦の幅に収めてから複数ページへ切り分け、1つのPDFファイルに保存します。ページ境界の手前で空白行を探し、文字や図の途中を避けます。空白行がない場合は境界付近を次ページの先頭に少し重ね、切れた部分も次ページで読めるようにします。文字を含む画像は可逆圧縮で格納します。途中の縦長画像を別ファイルとして保存することはありません。

PDFは撮影画面を画像として収める方式です。PDF内の文字は選択・検索できません。幅の広いページはA4縦に縮小するため、文字が小さくなる場合があります。撮影中にエラーや停止が発生した場合は未完成のPDFを保存しません。非常に長いページでは、完成した各ページの圧縮データを最後まで保持するため、ファイルサイズに応じてメモリと保存時間が増えます。

## 撮影方式

枠や iframe の高さを無理に広げず、表示されている範囲を実際にスクロールし、描画を待って撮影・結合します。これにより、画面に見える行だけを描く仮想リストや canvas の文書ビューアーも、その都度描画された内容を保存できます。別オリジンの iframe も、開いている文書をそのまま操作して撮影します。元の URL を別タブに開き直す処理はありません。

## 制限

- Chrome の保護されたページ・組み込み PDF ビューアーなど、拡張機能が内部を操作できない画面は対象外です。アクセスできない領域や、完全に隠れている領域ではエラーを表示します。
- 動画・アニメーション・撮影中に大きく配置が変わるページは、全体を同一時刻の画像にはできません。閉じた Shadow DOM や回転した要素にも制限があります。
- 撮影中に横幅が変わった場合は、誤った結合を避けるため停止します。読み込みが落ち着いてから再度撮影してください。
- 横幅の上限は 24,000 px、1回の撮影で扱う表示領域の上限は 1,200 回です。末尾のない無限スクロールなどで上限に達した場合は、完了とせずエラーを表示します。
